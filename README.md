# Blackjack Game (PHP)

PHP でオブジェクト指向・TDD・静的解析を実践しながら作成した、コンソールで遊べるブラックジャックゲームです。
ポートフォリオとして、「設計・テスト」を意識して実装することを目的に取り組みました。

## このプロジェクトで意識したこと

* **TDD（テスト駆動開発）**: 機能を実装する前にテストを書き、テストが通ることを確認しながら実装を進めました
* **単一責任・関心の分離**: カード / 手札 / 参加者 / 進行役 / 入出力をそれぞれ別クラスに分割し、1クラス1責務を意識しました
* **テスト容易性を意識した設計**: 標準入出力を `Input` / `Output` インターフェースで抽象化し、テストでは差し替え可能にしました
* **静的解析ツールの活用**: PHPStan / PHPMD / PHPCS を導入し、警告が出ない状態を保ちながら開発しました

## ゲーム概要

* あなた（プレイヤー）とディーラーに加え、CPU が自動操作する対戦相手を最大2人まで追加でき、**最大4人（ディーラー含む）で対戦**できます
* カードの点数は 2〜9 はそのまま、10/J/Q/K は10点、**A は1点または11点のうち合計が21以内で最大となる方**で自動的に数えます
* ディーラーはあなたの操作後、合計が17以上になるまで自動でカードを引きます
* 合計が21を超えた時点でバースト（負け）となります


## 設計・アーキテクチャ

```
src/Blackjack/
├── Card/
│   ├── Card.php        # 1枚のカード（スート＋ランク）
│   ├── Rank.php        # ランク（A, 2〜10, J, Q, K）と点数計算
│   └── Suit.php        # スート（♠♥♦♣）
├── Participant/
│   ├── Participant.php # プレイヤー・ディーラー・CPUの共通処理（抽象クラス）
│   ├── Player.php      # 人間が操作するプレイヤー
│   ├── CpuPlayer.php   # CPUが自動操作するプレイヤー
│   └── Dealer.php      # ディーラー（17点まで自動で引く）
├── Io/
│   ├── Input.php / ConsoleInput.php    # 入力の抽象化・標準入力実装
│   └── Output.php / ConsoleOutput.php  # 出力の抽象化・標準出力実装
├── Deck.php     # 山札（生成・シャッフル・ドロー）
├── Hand.php     # 手札（得点計算・バースト判定、Aの1/11点判定）
├── Judge.php    # 勝敗判定
├── Messages.php # 画面表示文言
└── Game.php     # ゲーム全体の進行役
```

`Input` / `Output` をインターフェースとして切り出すことで、実際のゲーム進行ロジック（`Game`）を標準入出力に依存させず、テストではダミー入力・出力に差し替えてユニットテストできるようにしています。

## 環境構築

```bash
# Docker イメージのビルド
docker-compose build

# Docker コンテナの起動
docker-compose up -d

# Docker コンテナ内でコマンドを実行する
docker-compose exec app php -v

# Docker コンテナの停止・削除
docker-compose down
```

### Remote Development (Dev Container) を使う場合

Docker イメージをビルド後、VSCode の Remote-Containers: Open Folder in Container からコンテナを開きます。コマンドはコンテナ内の VSCode ターミナルから実行してください。

devcontainer には Node.js と Claude Code CLI も同梱しているので、コンテナ内でそのまま `claude` コマンドが使えます。

```bash
docker-compose down  # 終了時
```

### デバッグ (Xdebug)

1. コードにブレークポイントを設定する
2. デバッグビューを開く
3. 「Listen for Xdebug」を選択してデバッグを開始する
4. コードを実行する

ブレークポイントで止まらない場合、 `.vscode/launch.json` の port が 9003 であることを確認してください。

## 実行方法

```bash
composer install
./bin/blackjack
```

起動すると対戦人数（あなたを含む人数）を聞かれるので入力してください。2人目以降はCPUが自動で操作します。

## テスト・静的解析

TDD で実装したため、主要なロジック（得点計算・A の1/11点判定・勝敗判定・CPU/ディーラーの挙動など）はすべてユニットテストでカバーしています。

```bash
composer phpunit  # テスト実行
composer phpstan  # 静的解析
composer phpcs    # コーディング規約チェック（PSR-12）
composer phpmd    # コード品質チェック
```
